Solucionario Paso a Paso: Identidades Trigonométricas

Grado Décimo (10°) - Demostraciones Completas

Tema 1: Identidades Recíprocas
1.\(\sin(x)\csc(x) = 1\)
Sabemos que \(\csc(x) = \frac{1}{\sin(x)}\)
\(\sin(x) \cdot \left(\frac{1}{\sin(x)}\right) = 1\)
Simplificando \(\sin(x)\) en numerador y denominador: \(1 = 1\) (L.Q.Q.D)
2.\(\frac{1}{\sec(x)} \cdot \csc(x) = \cot(x)\)
Sabemos que \(\frac{1}{\sec(x)} = \cos(x)\) y \(\csc(x) = \frac{1}{\sin(x)}\)
\(\cos(x) \cdot \frac{1}{\sin(x)} = \cot(x)\)
\(\frac{\cos(x)}{\sin(x)} = \cot(x)\)
\(\cot(x) = \cot(x)\)
3.\(\cos(x)\sec(x) + \tan(x)\cot(x) = 2\)
Por identidades recíprocas: \(\sec(x) = \frac{1}{\cos(x)}\) y \(\cot(x) = \frac{1}{\tan(x)}\)
\(\cos(x)\left(\frac{1}{\cos(x)}\right) + \tan(x)\left(\frac{1}{\tan(x)}\right) = 2\)
\(1 + 1 = 2 \implies 2 = 2\)
4.\(\sec(x)\csc(x)\sin(x) = \sec(x)\)
Reescribimos \(\csc(x) = \frac{1}{\sin(x)}\)
\(\sec(x) \cdot \left(\frac{1}{\sin(x)}\right) \cdot \sin(x) = \sec(x)\)
Cancelamos el seno: \(\sec(x) \cdot 1 = \sec(x)\)
\(\sec(x) = \sec(x)\)
5.\(\frac{\csc(x)}{\sec(x)} = \cot(x)\)
Expresamos todo en senos y cosenos: \(\csc(x) = \frac{1}{\sin(x)}\) y \(\sec(x) = \frac{1}{\cos(x)}\)
\(\frac{\frac{1}{\sin(x)}}{\frac{1}{\cos(x)}} = \cot(x)\)
Aplicando la ley de extremos y medios (oreja): \(\frac{\cos(x)}{\sin(x)} = \cot(x)\)
\(\cot(x) = \cot(x)\)
Tema 2: Identidades con Cocientes
6.\(\tan(x)\cos(x) = \sin(x)\)
Sabemos que \(\tan(x) = \frac{\sin(x)}{\cos(x)}\)
\(\left(\frac{\sin(x)}{\cos(x)}\right)\cos(x) = \sin(x)\)
Cancelando \(\cos(x)\): \(\sin(x) = \sin(x)\)
7.\(\frac{\tan(x)}{\sin(x)} = \sec(x)\)
Reemplazamos \(\tan(x)\): \(\frac{\frac{\sin(x)}{\cos(x)}}{\sin(x)}\)
Agregamos un 1 en el denominador para ley de oreja: \(\frac{\frac{\sin(x)}{\cos(x)}}{\frac{\sin(x)}{1}}\)
\(\frac{\sin(x)}{\sin(x)\cos(x)} = \frac{1}{\cos(x)}\)
\(\sec(x) = \sec(x)\)
8.\(\cot(x)\sin(x) = \cos(x)\)
Sabemos que \(\cot(x) = \frac{\cos(x)}{\sin(x)}\)
\(\left(\frac{\cos(x)}{\sin(x)}\right)\sin(x) = \cos(x)\)
Cancelando \(\sin(x)\): \(\cos(x) = \cos(x)\)
9.\(\sin(x) + \cos(x)\cot(x) = \csc(x)\)
Sustituimos \(\cot(x) = \frac{\cos(x)}{\sin(x)}\)
\(\sin(x) + \cos(x)\left(\frac{\cos(x)}{\sin(x)}\right) = \sin(x) + \frac{\cos^2(x)}{\sin(x)}\)
Sacamos factor común / sumamos fracciones: \(\frac{\sin^2(x) + \cos^2(x)}{\sin(x)}\)
Aplicamos identidad pitagórica (\(\sin^2(x) + \cos^2(x) = 1\)): \(\frac{1}{\sin(x)}\)
\(\csc(x) = \csc(x)\)
10.\(\frac{\cos(x)}{\cot(x)} + \frac{\sin(x)}{\tan(x)} = \sin(x) + \cos(x)\)
Convertimos los divisores: \(\cot(x) = \frac{\cos(x)}{\sin(x)}\) y \(\tan(x) = \frac{\sin(x)}{\cos(x)}\)
\(\frac{\cos(x)}{\frac{\cos(x)}{\sin(x)}} + \frac{\sin(x)}{\frac{\sin(x)}{\cos(x)}}\)
Simplificando las fracciones: \(\frac{\cos(x)\sin(x)}{\cos(x)} + \frac{\sin(x)\cos(x)}{\sin(x)}\)
\(\sin(x) + \cos(x) = \sin(x) + \cos(x)\)
Tema 3: Identidades Pitagóricas
11.\(1 - \sin^2(x) = \cos^2(x)\)
Partimos de la identidad fundamental: \(\sin^2(x) + \cos^2(x) = 1\)
Restamos \(\sin^2(x)\) en ambos lados: \(\cos^2(x) = 1 - \sin^2(x)\)
\(\cos^2(x) = \cos^2(x)\)
12.\(\sec^2(x) - \tan^2(x) = 1\)
Partimos de \(\sin^2(x) + \cos^2(x) = 1\)
Dividimos todos los términos entre \(\cos^2(x)\): \(\frac{\sin^2(x)}{\cos^2(x)} + \frac{\cos^2(x)}{\cos^2(x)} = \frac{1}{\cos^2(x)}\)
\(\tan^2(x) + 1 = \sec^2(x)\)
Restamos \(\tan^2(x)\): \(1 = \sec^2(x) - \tan^2(x)\)
13.\(\cos^2(x)(1 + \tan^2(x)) = 1\)
Sabemos del ejercicio anterior que \(1 + \tan^2(x) = \sec^2(x)\)
Sustituimos: \(\cos^2(x)(\sec^2(x)) = 1\)
\(\cos^2(x) \cdot \left(\frac{1}{\cos^2(x)}\right) = 1\)
\(1 = 1\)
14.\(\csc^2(x) - \cot^2(x) = \sin^2(x) + \cos^2(x)\)
Evaluamos el lado izquierdo: \(\csc^2(x) - \cot^2(x)\)
\(\frac{1}{\sin^2(x)} - \frac{\cos^2(x)}{\sin^2(x)} = \frac{1 - \cos^2(x)}{\sin^2(x)}\)
Como \(1 - \cos^2(x) = \sin^2(x)\), tenemos \(\frac{\sin^2(x)}{\sin^2(x)} = 1\)
Evaluamos el lado derecho: \(\sin^2(x) + \cos^2(x) = 1\)
\(1 = 1\)
15.\(\frac{1}{1-\sin^2(x)} - 1 = \tan^2(x)\)
Sustituimos el denominador \(1 - \sin^2(x) = \cos^2(x)\)
\(\frac{1}{\cos^2(x)} - 1 = \tan^2(x)\)
\(\sec^2(x) - 1 = \tan^2(x)\)
Sabemos que \(\sec^2(x) = 1 + \tan^2(x)\), así que \((1 + \tan^2(x)) - 1 = \tan^2(x)\)
\(\tan^2(x) = \tan^2(x)\)
Tema 4: Suma y Resta de Ángulos
16.\(\sin(x+y) + \sin(x-y) = 2\sin(x)\cos(y)\)
Expandimos las sumas de ángulos:
\(\sin(x+y) = \sin(x)\cos(y) + \cos(x)\sin(y)\)
\(\sin(x-y) = \sin(x)\cos(y) - \cos(x)\sin(y)\)
Al sumarlas, los términos \(\cos(x)\sin(y)\) se cancelan.
\(2\sin(x)\cos(y) = 2\sin(x)\cos(y)\)
17.\(\cos(x-y) - \cos(x+y) = 2\sin(x)\sin(y)\)
Expandimos los cosenos:
\(\cos(x-y) = \cos(x)\cos(y) + \sin(x)\sin(y)\)
\(\cos(x+y) = \cos(x)\cos(y) - \sin(x)\sin(y)\)
Restamos el segundo del primero:
\((\cos(x)\cos(y) + \sin(x)\sin(y)) - (\cos(x)\cos(y) - \sin(x)\sin(y))\)
\(2\sin(x)\sin(y) = 2\sin(x)\sin(y)\)
18.\(\frac{\sin(x+y)}{\cos(x)\cos(y)} = \tan(x) + \tan(y)\)
Expandimos el numerador: \(\sin(x+y) = \sin(x)\cos(y) + \cos(x)\sin(y)\)
Separamos la fracción: \(\frac{\sin(x)\cos(y)}{\cos(x)\cos(y)} + \frac{\cos(x)\sin(y)}{\cos(x)\cos(y)}\)
Simplificamos cancelando los cosenos: \(\frac{\sin(x)}{\cos(x)} + \frac{\sin(y)}{\cos(y)}\)
\(\tan(x) + \tan(y) = \tan(x) + \tan(y)\)
19.\(\cos(\frac{\pi}{2} - x) = \sin(x)\)
Aplicamos la fórmula de resta de coseno: \(\cos(A-B) = \cos(A)\cos(B) + \sin(A)\sin(B)\)
\(\cos(\frac{\pi}{2})\cos(x) + \sin(\frac{\pi}{2})\sin(x)\)
Sabemos que \(\cos(\frac{\pi}{2}) = 0\) y \(\sin(\frac{\pi}{2}) = 1\)
\(0 \cdot \cos(x) + 1 \cdot \sin(x) = \sin(x)\)
20.\(\frac{\tan(x+y) - \tan(x)}{1 + \tan(x+y)\tan(x)} = \tan(y)\)
Identificamos la fórmula de la tangente de una resta: \(\tan(A - B) = \frac{\tan(A) - \tan(B)}{1 + \tan(A)\tan(B)}\)
Donde \(A = (x+y)\) y \(B = x\)
Reemplazando: \(\tan((x+y) - x) = \tan(y)\)
\(\tan(y) = \tan(y)\)
Tema 5: Ángulos Opuestos (Pares e Impares)
21.\(\sin(-x) + \sin(x) = 0\)
La función seno es impar, por lo tanto: \(\sin(-x) = -\sin(x)\)
Reemplazando: \(-\sin(x) + \sin(x) = 0\)
\(0 = 0\)
22.\(\cos(-x)\sec(x) = 1\)
La función coseno es par: \(\cos(-x) = \cos(x)\)
Reescribimos \(\sec(x) = \frac{1}{\cos(x)}\)
\(\cos(x) \cdot \frac{1}{\cos(x)} = 1\)
\(1 = 1\)
23.\(\tan(-x)\cot(-x) = 1\)
Ambas son funciones impares: \(\tan(-x) = -\tan(x)\) y \(\cot(-x) = -\cot(x)\)
\((-\tan(x)) \cdot (-\cot(x)) = \tan(x)\cot(x)\)
Por identidades recíprocas, \(\tan(x)\left(\frac{1}{\tan(x)}\right) = 1\)
\(1 = 1\)
24.\(\sin(-x)\csc(x) + \cos(-x)\sec(-x) = 0\)
Paridad: \(\sin(-x) = -\sin(x)\), \(\cos(-x) = \cos(x)\) y \(\sec(-x) = \sec(x)\)
\((-\sin(x))\left(\frac{1}{\sin(x)}\right) + (\cos(x))\left(\frac{1}{\cos(x)}\right) = 0\)
\(-1 + 1 = 0\)
\(0 = 0\)
25.\(\frac{\cos(-x)}{1+\sin(-x)} + \frac{\cos(-x)}{1-\sin(-x)} = 2\sec(x)\)
Aplicamos paridad: \(\frac{\cos(x)}{1-\sin(x)} + \frac{\cos(x)}{1+\sin(x)}\)
Sumamos fracciones: \(\frac{\cos(x)(1+\sin(x)) + \cos(x)(1-\sin(x))}{(1-\sin(x))(1+\sin(x))}\)
Simplificando numerador: \(\cos(x) + \cos(x)\sin(x) + \cos(x) - \cos(x)\sin(x) = 2\cos(x)\)
Simplificando denominador: \(1 - \sin^2(x) = \cos^2(x)\)
Queda: \(\frac{2\cos(x)}{\cos^2(x)} = \frac{2}{\cos(x)} = 2\sec(x)\)
Tema 6: Operaciones y Factorización Algebraica
26.\(\sin^2(x) + \sin^2(x)\tan^2(x) = \tan^2(x)\)
Sacamos factor común \(\sin^2(x)\): \(\sin^2(x)[1 + \tan^2(x)]\)
Por identidad pitagórica, \(1 + \tan^2(x) = \sec^2(x)\)
\(\sin^2(x) \cdot \sec^2(x) = \sin^2(x) \cdot \frac{1}{\cos^2(x)}\)
\(\frac{\sin^2(x)}{\cos^2(x)} = \tan^2(x)\)
27.\((\sin(x) - \cos(x))(\sin(x) + \cos(x)) = 1 - 2\cos^2(x)\)
Aplicamos diferencia de cuadrados \((A-B)(A+B) = A^2 - B^2\):
\(\sin^2(x) - \cos^2(x)\)
Sustituimos \(\sin^2(x)\) por \(1 - \cos^2(x)\):
\((1 - \cos^2(x)) - \cos^2(x) = 1 - 2\cos^2(x)\)
28.\(\frac{\sec^4(x) - 1}{\tan^2(x)} = \sec^2(x) + 1\)
Factorizamos el numerador como diferencia de cuadrados:
\(\frac{(\sec^2(x) - 1)(\sec^2(x) + 1)}{\tan^2(x)}\)
Sabemos que \(\sec^2(x) - 1 = \tan^2(x)\)
\(\frac{\tan^2(x)(\sec^2(x) + 1)}{\tan^2(x)}\)
Cancelando \(\tan^2(x)\): \(\sec^2(x) + 1 = \sec^2(x) + 1\)
29.\(\frac{1}{1-\cos(x)} + \frac{1}{1+\cos(x)} = 2\csc^2(x)\)
Sumamos las fracciones buscando denominador común:
\(\frac{(1+\cos(x)) + (1-\cos(x))}{(1-\cos(x))(1+\cos(x))}\)
Numerador: \(1 + \cos(x) + 1 - \cos(x) = 2\)
Denominador: \(1 - \cos^2(x) = \sin^2(x)\)
\(\frac{2}{\sin^2(x)} = 2\csc^2(x)\)
30.\(\frac{\cos^3(x) - \sin^3(x)}{\cos(x) - \sin(x)} = 1 + \sin(x)\cos(x)\)
Factorizamos la diferencia de cubos: \(A^3 - B^3 = (A-B)(A^2 + AB + B^2)\)
\(\frac{(\cos(x) - \sin(x))(\cos^2(x) + \cos(x)\sin(x) + \sin^2(x))}{\cos(x) - \sin(x)}\)
Cancelamos el término \((\cos(x) - \sin(x))\):
\(\cos^2(x) + \sin^2(x) + \cos(x)\sin(x)\)
Agrupamos identidades: \(1 + \sin(x)\cos(x) = 1 + \sin(x)\cos(x)\)
