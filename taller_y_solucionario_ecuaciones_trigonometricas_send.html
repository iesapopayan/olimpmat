Taller y Solucionario: Ecuaciones Trigonométricas

Grado Décimo (10°) - Matemáticas

Soluciones paso a paso para el intervalo \(-180^\circ < x \le 180^\circ\) (\((-\pi, \pi]\))

Indicaciones del Taller: Resuelva cada una de las 20 ecuaciones trigonométricas determinando todos los valores angulares posibles para \(x\) en el intervalo \(-180^\circ < x \le 180^\circ\). Este es el rango estándar de salida (valor principal y sus simétricos/periódicos) que arroja una calculadora científica.
Nivel 1: Despeje Directo y Ángulos Notables
1. \(2\cos(x) - 1 = 0\)
Despejamos el coseno: \(2\cos(x) = 1 \implies \cos(x) = \frac{1}{2}\)
Con la calculadora obtenemos el valor principal: \(x_1 = \arccos(0.5) = 60^\circ\)
Como la función coseno es par (\(\cos(-x) = \cos(x)\)), la otra solución en el intervalo es su opuesto:
\(x_2 = -60^\circ\)
Conjunto Solución: \(x \in \{-60^\circ, 60^\circ\}\)
2. \(\sqrt{2}\sin(x) + 1 = 0\)
Despejamos el seno: \(\sqrt{2}\sin(x) = -1 \implies \sin(x) = -\frac{\sqrt{2}}{2}\)
Con la calculadora obtenemos el valor principal: \(x_1 = \arcsin(-\frac{\sqrt{2}}{2}) = -45^\circ\)
El seno también es negativo en el tercer cuadrante. Para hallar el otro ángulo, usamos la simetría \(\sin(-180^\circ - x) = \sin(x)\):
\(x_2 = -180^\circ - (-45^\circ) = -135^\circ\)
Conjunto Solución: \(x \in \{-135^\circ, -45^\circ\}\)
3. \(\sqrt{3}\tan(x) - 1 = 0\)
Despejamos la tangente: \(\tan(x) = \frac{1}{\sqrt{3}} = \frac{\sqrt{3}}{3}\)
El valor principal de la calculadora es: \(x_1 = \arctan(\frac{\sqrt{3}}{3}) = 30^\circ\)
La función tangente tiene periodo de \(180^\circ\). Para mantenernos en el intervalo restamos \(180^\circ\):
\(x_2 = 30^\circ - 180^\circ = -150^\circ\)
Conjunto Solución: \(x \in \{-150^\circ, 30^\circ\}\)
4. \(2\sin(x) - \sqrt{3} = 0\)
Despejamos el seno: \(\sin(x) = \frac{\sqrt{3}}{2}\)
Valor principal: \(x_1 = \arcsin(\frac{\sqrt{3}}{2}) = 60^\circ\)
El seno también es positivo en el segundo cuadrante (\(180^\circ - x\)):
\(x_2 = 180^\circ - 60^\circ = 120^\circ\)
Conjunto Solución: \(x \in \{60^\circ, 120^\circ\}\)
5. \(3\tan^2(x) - 3 = 0\)
Despejamos \(\tan^2(x)\): \(3\tan^2(x) = 3 \implies \tan^2(x) = 1\)
Extraemos raíz cuadrada: \(\tan(x) = 1\) ó \(\tan(x) = -1\)
Para \(\tan(x) = 1\): \(x_1 = 45^\circ\) y \(x_2 = 45^\circ - 180^\circ = -135^\circ\)
Para \(\tan(x) = -1\): \(x_3 = -45^\circ\) y \(x_4 = -45^\circ + 180^\circ = 135^\circ\)
Conjunto Solución: \(x \in \{-135^\circ, -45^\circ, 45^\circ, 135^\circ\}\)
Nivel 2: Factorización y Forma Cuadrática
6. \(\sin(x)\cos(x) - \cos(x) = 0\)
Factorizamos \(\cos(x)\): \(\cos(x)(\sin(x) - 1) = 0\)
Caso 1: \(\cos(x) = 0 \implies x_1 = 90^\circ, x_2 = -90^\circ\)
Caso 2: \(\sin(x) - 1 = 0 \implies \sin(x) = 1 \implies x_3 = 90^\circ\)
Conjunto Solución: \(x \in \{-90^\circ, 90^\circ\}\)
7. \(2\sin^2(x) - \sin(x) - 1 = 0\)
Factorizamos: \((2\sin(x) + 1)(\sin(x) - 1) = 0\)
Factor 1: \(2\sin(x) + 1 = 0 \implies \sin(x) = -0.5\)
Valor principal: \(-30^\circ\). La otra solución (cuadrante III) es \(-180^\circ - (-30^\circ) = -150^\circ\)
Factor 2: \(\sin(x) - 1 = 0 \implies \sin(x) = 1 \implies x = 90^\circ\)
Conjunto Solución: \(x \in \{-150^\circ, -30^\circ, 90^\circ\}\)
8. \(2\cos^2(x) + \cos(x) = 0\)
Factor común \(\cos(x)\): \(\cos(x)(2\cos(x) + 1) = 0\)
Caso 1: \(\cos(x) = 0 \implies x \in \{-90^\circ, 90^\circ\}\)
Caso 2: \(\cos(x) = -0.5 \implies x = \arccos(-0.5) = 120^\circ\)
La otra solución por simetría par es \(-120^\circ\).
Conjunto Solución: \(x \in \{-120^\circ, -90^\circ, 90^\circ, 120^\circ\}\)
9. \(\tan^2(x) + \tan(x) = 0\)
Factor común \(\tan(x)\): \(\tan(x)(\tan(x) + 1) = 0\)
Caso 1: \(\tan(x) = 0 \implies x_1 = 0^\circ, x_2 = 180^\circ\)
Caso 2: \(\tan(x) = -1 \implies x_3 = -45^\circ\). Sumando el periodo: \(x_4 = -45^\circ + 180^\circ = 135^\circ\)
Conjunto Solución: \(x \in \{-45^\circ, 0^\circ, 135^\circ, 180^\circ\}\)
10. \(2\cos^2(x) - 3\cos(x) + 1 = 0\)
Factorizamos la cuadrática: \((2\cos(x) - 1)(\cos(x) - 1) = 0\)
Factor 1: \(2\cos(x) - 1 = 0 \implies \cos(x) = 0.5 \implies x \in \{-60^\circ, 60^\circ\}\)
Factor 2: \(\cos(x) - 1 = 0 \implies \cos(x) = 1 \implies x = 0^\circ\)
Conjunto Solución: \(x \in \{-60^\circ, 0^\circ, 60^\circ\}\)
Nivel 3: Identidades Pitagóricas y Recíprocas
11. \(2\sin^2(x) + \cos(x) = 1\)
Identidad pitagórica \(\sin^2(x) = 1 - \cos^2(x)\):
\(2(1 - \cos^2(x)) + \cos(x) - 1 = 0 \implies -2\cos^2(x) + \cos(x) + 1 = 0\)
Multiplicando por \(-1\) y factorizando: \((2\cos(x) + 1)(\cos(x) - 1) = 0\)
\(2\cos(x) + 1 = 0 \implies \cos(x) = -0.5 \implies x \in \{-120^\circ, 120^\circ\}\)
\(\cos(x) - 1 = 0 \implies \cos(x) = 1 \implies x = 0^\circ\)
Conjunto Solución: \(x \in \{-120^\circ, 0^\circ, 120^\circ\}\)
12. \(\sec^2(x) + 2\tan(x) = 4\)
Sustituimos \(\sec^2(x) = 1 + \tan^2(x)\):
\(\tan^2(x) + 2\tan(x) - 3 = 0 \implies (\tan(x) + 3)(\tan(x) - 1) = 0\)
Factor 1: \(\tan(x) = 1 \implies x_1 = 45^\circ\). Con el periodo: \(x_2 = 45^\circ - 180^\circ = -135^\circ\)
Factor 2: \(\tan(x) = -3 \implies x_3 = \arctan(-3) \approx -71.57^\circ\). Con el periodo: \(x_4 = -71.57^\circ + 180^\circ = 108.43^\circ\)
Conjunto Solución: \(x \in \{-135^\circ, \approx -71.57^\circ, 45^\circ, \approx 108.43^\circ\}\)
13. \(\cos^2(x) - \sin^2(x) = 0\)
Dividimos entre \(\cos^2(x)\): \(1 - \tan^2(x) = 0 \implies \tan^2(x) = 1\)
\(\tan(x) = 1 \implies x \in \{-135^\circ, 45^\circ\}\)
\(\tan(x) = -1 \implies x \in \{-45^\circ, 135^\circ\}\)
Conjunto Solución: \(x \in \{-135^\circ, -45^\circ, 45^\circ, 135^\circ\}\)
14. \(\sin(x) + \csc(x) = \frac{5}{2}\)
Sustituimos \(\csc(x) = \frac{1}{\sin(x)}\): \(\sin(x) + \frac{1}{\sin(x)} = 2.5\)
Multiplicando por \(\sin(x)\): \(\sin^2(x) - 2.5\sin(x) + 1 = 0\)
Multiplicamos por 2 para facilitar: \(2\sin^2(x) - 5\sin(x) + 2 = 0 \implies (2\sin(x) - 1)(\sin(x) - 2) = 0\)
\(\sin(x) = 2\) se descarta. Queda \(\sin(x) = 0.5 \implies x = 30^\circ, 150^\circ\)
Conjunto Solución: \(x \in \{30^\circ, 150^\circ\}\)
15. \(2\cos^2(x) + 3\sin(x) - 3 = 0\)
Sustituimos \(\cos^2(x) = 1 - \sin^2(x)\):
\(2(1 - \sin^2(x)) + 3\sin(x) - 3 = 0 \implies -2\sin^2(x) + 3\sin(x) - 1 = 0\)
Factorizamos: \((2\sin(x) - 1)(\sin(x) - 1) = 0\)
\(2\sin(x) - 1 = 0 \implies \sin(x) = 0.5 \implies x \in \{30^\circ, 150^\circ\}\)
\(\sin(x) - 1 = 0 \implies \sin(x) = 1 \implies x = 90^\circ\)
Conjunto Solución: \(x \in \{30^\circ, 90^\circ, 150^\circ\}\)
Nivel 4: Ángulo Doble y Ecuaciones de Síntesis
16. \(\sin(2x) = \sin(x)\)
Usamos la identidad del ángulo doble: \(2\sin(x)\cos(x) - \sin(x) = 0 \implies \sin(x)(2\cos(x) - 1) = 0\)
Caso 1: \(\sin(x) = 0 \implies x_1 = 0^\circ, x_2 = 180^\circ\)
Caso 2: \(\cos(x) = 0.5 \implies x_3 = 60^\circ, x_4 = -60^\circ\)
Conjunto Solución: \(x \in \{-60^\circ, 0^\circ, 60^\circ, 180^\circ\}\)
17. \(\cos(2x) - \cos(x) = 0\)
Sustituimos \(\cos(2x) = 2\cos^2(x) - 1\):
\(2\cos^2(x) - \cos(x) - 1 = 0 \implies (2\cos(x) + 1)(\cos(x) - 1) = 0\)
\(2\cos(x) + 1 = 0 \implies \cos(x) = -0.5 \implies x \in \{-120^\circ, 120^\circ\}\)
\(\cos(x) - 1 = 0 \implies \cos(x) = 1 \implies x = 0^\circ\)
Conjunto Solución: \(x \in \{-120^\circ, 0^\circ, 120^\circ\}\)
18. \(\sin(2x) - \sqrt{3}\cos(x) = 0\)
Sustituimos \(\sin(2x) = 2\sin(x)\cos(x)\):
\(\cos(x)(2\sin(x) - \sqrt{3}) = 0\)
Caso 1: \(\cos(x) = 0 \implies x \in \{-90^\circ, 90^\circ\}\)
Caso 2: \(\sin(x) = \frac{\sqrt{3}}{2} \implies x_1 = 60^\circ, x_2 = 180^\circ - 60^\circ = 120^\circ\)
Conjunto Solución: \(x \in \{-90^\circ, 60^\circ, 90^\circ, 120^\circ\}\)
19. \(\tan(2x) = \sqrt{3}\)
Sea \(\theta = 2x\). La solución general para \(\tan(\theta) = \sqrt{3}\) es \(\theta = 60^\circ + 180^\circ k\) (donde \(k\) es un entero).
Despejando \(x\): \(x = 30^\circ + 90^\circ k\)
Evaluamos para obtener soluciones en el rango \((-180^\circ, 180^\circ]\):
Si \(k=-2 \implies x = -150^\circ\)
Si \(k=-1 \implies x = -60^\circ\)
Si \(k=0 \implies x = 30^\circ\)
Si \(k=1 \implies x = 120^\circ\)
Conjunto Solución: \(x \in \{-150^\circ, -60^\circ, 30^\circ, 120^\circ\}\)
20. \(\sin(x) - \cos(x) = 1\)
Elevamos al cuadrado: \((\sin(x) - \cos(x))^2 = 1 \implies \sin^2(x) - 2\sin(x)\cos(x) + \cos^2(x) = 1\)
\(1 - \sin(2x) = 1 \implies \sin(2x) = 0 \implies 2x = 0^\circ, 180^\circ, -180^\circ, 360^\circ\)
Por lo que las posibles soluciones son: \(x \in \{-90^\circ, 0^\circ, 90^\circ, 180^\circ\}\)
Descartando soluciones extrañas (comprobación):
\(x = 0^\circ \implies 0 - 1 = -1 \neq 1\) (Falso)
\(x = 90^\circ \implies 1 - 0 = 1\) (Verdadero)
\(x = 180^\circ \implies 0 - (-1) = 1\) (Verdadero)
\(x = -90^\circ \implies -1 - 0 = -1 \neq 1\) (Falso)
Conjunto Solución: \(x \in \{90^\circ, 180^\circ\}\)
